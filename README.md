
# 🪐 VIPERR Showcase Landing Page (Kai Angel & 9mice Edition)

A high-fidelity, fully responsive desktop-and-mobile promotional landing page dedicated to the experimental rap duo **VIPERR**. This site acts as the front-end gateway for the unified Telegram Media Assistant Bot, providing a visually immersive experience built purely with modern semantic HTML5 and vanilla CSS3.

## 🔗 Live Demo
Check out the production release live at: **pazan4ok-droid.github.io/viperr.github.io/**

## 🚀 Key Structural Features
- **Desktop Split-Screen Layout:** The hero section implements a balanced 50/50 split viewport architecture, rendering high-contrast cover art on the left and optimized copy on the right.
- **Bi-Column Grid Ecosystem:** The cast section leverages CSS Grid (`grid-template-columns: 1fr 1fr`) to distribute artist-specific profile nodes symmetrically.
- **Deep Mobile Adaptation:** Utilizes precise `@media (max-width: 768px)` overrides to seamlessly downscale text elements, convert rigid multi-column states into fluid single-column columns, and rigidly enforce image aspect ratios (`object-fit: cover`) to avoid stretching across diverse iOS and Android viewports.
- **Viperr Aesthetics & Typography:** Custom UI features linear neon gradients, glow text-shadows (`rgba(107, 17, 255, 0.6)`), custom hover micro-interactions, and crisp modern typography.

## 🛠 Tech Stack
- **Frontend:** Semantic HTML5, CSS3 (Flexbox, CSS Grid, Media Queries)
- **Deployment:** **GitHub Pages** (Automated static hosting pipeline)
- **Integration:** Directly routes web traffic to the internal asynchronous Python backend via Telegram's deep-linking schema.
